# Moemzade.ge

საქართველოს მასწავლებლების, კურსებისა და ტრენერების სამენოვანი საძიებო პლატფორმა.

ეს რეპოზიტორია არის ახალი PHP 8.3 + MySQL ვერსია, რომელიც გათვლილია shared hosting-ზე. ძველი Google Sheet/Apps Script ვერსია აქ აღარ გამოიყენება.

## MVP-ში შედის

- მასწავლებლების ძებნა სფეროს, რეგიონის, ფორმატის, ენისა და საკვანძო სიტყვის მიხედვით;
- მასწავლებლის საჯარო პროფილი და პირდაპირ ხილული ტელეფონის ნომერი;
- ავტომატური matching და უშედეგო მოთხოვნების სტატისტიკა;
- ერთი ანონიმური ბრაუზერის ერთი კომენტარი თითო მასწავლებელზე (ხელახლა გაგზავნა არსებულს აახლებს);
- კომენტარების ადმინისტრატორის მიერ დამტკიცება;
- პროფილისა და საიტის ყოველდღიური უნიკალური ვიზიტორების ანონიმური სტატისტიკა;
- მხოლოდ ადმინისტრატორის ავტორიზაცია და მასწავლებლების მართვა;
- ფოტოების WebP ოპტიმიზაცია და Local/Cloudflare R2 საცავის მხარდაჭერა;
- ქართული, ინგლისური და რუსული ინტერფეისი;
- Privacy, Terms და Cookie გვერდები.

## ლოკალური გაშვება

1. დააკოპირე `.env.example` როგორც `.env` და ჩაწერე უნიკალური `APP_KEY`, MySQL მონაცემები და ადმინისტრატორის password hash.
2. შექმენი ბაზა და გაუშვი `php bin/migrate.php`.
3. ადმინისტრატორის hash მიიღე ბრძანებით `php bin/hash-password.php "ძლიერი-პაროლი"`.
4. დეველოპმენტისთვის გაუშვი `php -S 127.0.0.1:8080 index.php`.

Apache shared hosting-ზე routing-ს `.htaccess` მართავს. ვებ-სერვერს უნდა ჰქონდეს PHP 8.3, `pdo_mysql`, `mbstring`, სურათებისთვის Imagick ან GD WebP და R2-ის გამოყენებისას `curl`.

ჰოსტინგთან GitHub deployment-ის დაკავშირების ზუსტი ნაბიჯები წერია [`docs/DEPLOYMENT.md`](docs/DEPLOYMENT.md)-ში. deployment workflow დაემატება მას შემდეგ, რაც დაზუსტდება ProService-ის პროტოკოლი, სერვერის მისამართი და web root.

## უსაფრთხოება

`.env` და პირადი გასაღებები GitHub-ში არასოდეს იტვირთება. ბაზაში არ ინახება სრული IP ან ბრაუზერის ანონიმური კოდი — ინახება მხოლოდ HMAC hash. საჯარო კომენტარები გამოჩნდება მხოლოდ ადმინისტრატორის დამტკიცების შემდეგ.
